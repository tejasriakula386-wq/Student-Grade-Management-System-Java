# Student Grade Management System | Java

A dynamic console-based Student Grade Management System developed using Core Java concepts.  
This project allows users to enter student details, subject names, and marks dynamically to calculate grades, percentage, and final results.

## Features
- Enter Student Name and Roll Number
- Dynamic Subject Entry
- Dynamic Marks Calculation
- Total Marks Calculation
- Average and Percentage Calculation
- Grade Evaluation
- Pass/Fail Detection
- Menu-Driven Console Interface

## Technologies Used
- Core Java
- Arrays
- Scanner Class
- Conditional Statements
- Loops
- Switch Case

## Concepts Used
- Arrays and Dynamic Input Handling
- Loops and Iteration
- Conditional Statements
- User Input Handling
- Problem Solving Logic
- Basic Programming Fundamentals

## How to Run

### Step 1: Compile the Program
```bash
javac Main.java
```

### Step 2: Run the Program
```bash
java Main
```

## Sample Functionalities
- Accept multiple subjects dynamically
- Store and display subject-wise marks
- Calculate total marks and average
- Generate grade based on performance
- Detect fail condition if marks are below passing criteria
